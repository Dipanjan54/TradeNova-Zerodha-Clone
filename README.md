TradeNova - Zerodha Clone

A full-stack trading platform inspired by Zerodha, built with modern web technologies.

📋 Overview

TradeNova is a comprehensive stock trading application that replicates the core functionality of Zerodha's trading platform. It includes a landing page, user authentication, a trading dashboard, and real-time portfolio management.

✅ Completed
